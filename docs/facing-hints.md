# Early terrain-facing rejection — experiment

Store a six-direction hint in vertex B's unused flag slot; vertex A's material/entity flag and every position/UV/light/colour component remain unchanged. Original shaders ignore this slot, so reference and candidate share the same tagged payload and original traversal order. No extra texture allocation.

Tag only terrain triangles lying exactly in a coordinate plane, with a zero projected edge component and finite nondegenerate area. The zero component prevents subtractive cancellation in the relevant determinant. A direction pointing away from the face or parallel to it is already rejected by the original one-sided Moller–Trumbore determinant test. The candidate rejects these after fetching vertex B, saving vertex C and the remaining intersection arithmetic. Other triangles, entities and clouds follow the original test. Entering a leaf still disables empty-box publication; a directional rejection is not an empty-space certificate.

The candidate is a separate diagnostic/default program on top of cap16. X toggles; Shift+X compares against the accepted triangle-culling program. Both shaders see the hints in unused padding; no claim is made about hardware texture compression effects from those padding bits.
